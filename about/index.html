项目

  • 本科毕业设计：SAR 成像质量评估软件

    本项目开发了一款基于 Matlab 与 C++ 混合编程的合成孔径雷达（SAR）成像质量综合评估软件 ；用户可导入回波或图像数据，一站式实现回波信号相位分析、Chirp Scaling 算法成像以及点目标质量指标（如分辨率、旁瓣比等）的定量计算 ，适用于辅助验证 SAR 成像算法性能与鉴定雷达图像产品质量 。

  • 开源项目：DanbooruSearchOnline

    ❤+⭐:80，总搜索次数30000+

    本项目提供一种基于语义匹配的 Danbooru 标签查找方案。用户可以通过输入日常语言或模糊描述，查找并匹配 Danbooru 数据集中对应的标准标签，适用于辅助构建 Stable Diffusion、NovelAI 等 AI 绘画工具的提示词。

  • 开源项目：ComfyUI-NewBie-LLM-Formatter

    ⭐:46，总下载次数700+

    本项目利用大语言模型 API 将自然语言或图片自动转化为适用于 NewBie 模型的结构化 XML 提示词。通过提供高度健壮的提示词生成与画面风格管理节点，显著提升了图像生成流程的效率与效果。
