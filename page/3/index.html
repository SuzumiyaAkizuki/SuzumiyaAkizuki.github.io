核心能力
多维度语义匹配

底层构建 4 个向量空间（英文、中文扩展词、维基释义、中文核心词），输入中文描述或英文模糊拼写均可精准命中。拼写错误、罗马音、词形变体自动容错。

智能分词与显式分隔

长句自动拆分关键概念分别检索；也支持用空格、逗号、顿号手动分隔，每个片段作为原子概念匹配。≤7 字片段保持完整，>7 字自动回退分词。

标签关联推荐

基于 NPMI 共现统计，选中标签后自动推荐常一起出现的搭配标签。多标签取交集，精准定位特定场景下的专属搭配。

推荐擅长画师

根据已选标签实时推荐擅长绘制这些元素的画师，按 NPMI 共现评分排序，画师可勾选加入已选标签。

搜索方式
精确查词

知道大概写法但不确定拼写，或只记得部分写法。通过语义相似度而非字符串匹配，具备拼写容错能力。

建议参数： Top K: 10 | 结果上限: 10 | 热度权重: 0.15 | 关闭智能分词

输入 命中标签 说明
selafuku serafuku 经典拼写错误
twintail twintails 单复数混淆
zettai ryouiki zettai_ryouiki 罗马音输入
概念模糊发散

脑中有模糊概念但不知道对应哪些标签，系统帮你「发散」出全部候选。输入「兔耳朵」返回真兔耳、头饰耳、兽娘耳等变体；输入「中国风古装」返回汉服、旗袍、各朝代服制。

建议参数： Top K: 80~160 | 结果上限: 80 | 热度权重: 0.15 | 开启智能分词

完整画面转换

描述一整幅画面，自动拆词、分别匹配、合并去重，输出覆盖尽可能多画面元素的完整 prompt。

建议参数： Top K: 5 | 结果上限: 80 | 热度权重: 0.15 | 开启智能分词

输入示例：

一个穿着白色水手服、蓝色短裙的少女，在下着大雨的城市街道奔跑，
她的表情是不甘、愤怒、流泪，她的衣服湿透。

输出标签：short_dress city streaming_tears street white_serafuku furious rain running crying ...

标签关联推荐（共现匹配）

不依赖语义相似度，而是基于 Danbooru 图库中标签的共现统计。NPMI 评分有效过滤仅因自身热度高而频繁出现的标签。 同时勾选多个标签时，综合计算多标签的共现关系，推荐与这组标签整体最匹配的标签。例如 maid + twintails 会倾向于「女仆且双马尾」场景下的专属搭配。

推荐擅长画师

基于标签-画师 NPMI 共现数据。对每个已选标签计算与画师的共现分，累加后乘以命中标签数加权，归一化为百分比。画师可勾选加入已选标签（Anima 模式自动加 @ 前缀）。

使用入口
在线网页

直接访问 HuggingFace Space，无需部署。支持中文和英文搜索，提供 NSFW 保护模式、维基释义悬浮提示、标签名跳转 Danbooru 原站。 HF Space 无流量时休眠，首次请求需等待冷启动（约 30~60 秒）。

REST API

标准 RESTful 接口，启动后访问 /api/docs 查看交互式文档。三个端点： POST /api/search — 自然语言搜索标签 POST /api/related — 共现关联推荐 POST /api/artists — 推荐擅长画师

MCP 协议

接入 Claude Desktop、Cursor、Cherry Studio 等支持 MCP 的客户端。三个工具：search_tags、get_related_tags、get_artist_recommendations。

服务地址： https://sakizuki-danboorusearch.hf.space/mcp/mcp Claude Desktop 需通过 mcp-remote 桥接（npm install -g mcp-remote），图形界面客户端选择 Streamable HTTP 类型直接连接。

数据与技巧
数据来源与覆盖范围

数据来源：Danbooru API 抓取，中文翻译与语义扩充由 LLM 辅助完成。角色名、作品名通过 Bangumi API 精确查询，避免幻觉。 仅收录频数 ≥100 的标签，覆盖 General（通用特征）、Character（角色）、Copyright（作品）三类。

数据库生成代码：github.com/SuzumiyaAkizuki/danbooru-tag-pipeline

搜索技巧与注意事项

先宽后窄：先用完整画面查找拿到大量候选，再勾选触发关联推荐补充遗漏细节。

悬浮查看释义：鼠标悬停在标签行上弹出 Danbooru 维基释义，无需跳转。

显式分隔精细控制：「运动社团 校队 比赛」每个概念原样保留；「反乌托邦、赛博朋克、废土」逗号分隔同理。

NSFW 保护模式：默认关闭，打开后标签完整名称和含义会显示出来。

技术实现
RAG 检索与融合策略

双路召回：

向量检索 — ChromaDB 双 collection（content + title），权重 7:3

关键词检索 — BM25 + jieba 分词

多路融合：RRF（k=60）合并多个查询和多个召回通路的结果。

Multi-Query：用户问题先经 DeepSeek 重写为 2~4 个关键词再分别检索，扩大召回覆盖面。

相邻 chunk 扩展：fetch_adjacent() 供 fetch_context 工具使用，支持上下文溯源。

SSE 流式响应机制

同步 Agent 通过 loop.run_in_executor 跑在线程池中，asyncio.Queue 桥接同步 Agent 到异步 FastAPI。

SSE 事件类型：

事件 说明
token 逐 token 流式输出
token_flush 已推送的 token 转为「思考过程」样式
tool_start 工具调用开始
tool_done 工具调用完成
answer 最终答案
error 错误信息

120 秒超时保护。

DanbooruSearch MCP 集成细节

双端点自动切换：HF Space（主）+ ModelScope（备），调用失败自动切换。

连接管理：每次工具调用前重新握手（HF 多副本部署，session id 跨副本会 404）。

限流处理：429 限流时指数退避重试（5s → 10s → 20s，最多 3 次）。

工具定义：动态从 MCP tools/list 加载，失败回退硬编码 fallback。

核心能力
Agent 智能搜索

LLM 在生成提示词的过程中调用 DanbooruSearch MCP 服务，实时搜索标签库，像人类一样查找、验证、补充标签，消除幻觉。

等级 行为 适用场景
Close 关闭 Agent，传统单轮 LLM 调用 已有完整标签、追求速度
Low 流水线模式：批量搜索 + LLM 直接组装，1 轮完成 追求最快速度
Medium Agent 循环：多轮迭代搜索，最多 8 轮 日常使用，平衡
High Agent 循环：宽召回 + 深探索，最多 10 轮 复杂场景、多人物

纯标签输入 1 轮直出；混合输入（标签 + 自然语言）自动划定搜索边界；支持单轮多工具并行调用。

双模式输出

NewBie 模式：生成结构化 XML 提示词，内置 lxml 自动修复。输出包含<character> <general_tags> 等语义化标签。

Anima 模式：生成 ## Prompt（标签块 + 英文自然语言段落）+ ## 中文解释（分点设计说明）的 Markdown 格式。标签分隔符为空格，画师使用 @ 前缀。

两种模式在节点内无缝切换，Agent 模式兼容两者。

多模态视觉反推

支持传入图片，利用多模态大模型直接反推生成高精度提示词。这是让 LLM 反推提示词，而非图生图。

迭代修改提速

同一会话内微调提示词时（改发色、换画风、增删标签、调整权重），自动识别改动范围，只重做变化部分、复用其余结果，大幅减少等待时间和 Token 消耗。

完全相同的输入（仅标点、空格差异）直接返回上次结果，零等待、零消耗。Low（流水线）模式同样支持此提速。

ComfyUI 节点
LLM Prompt Formatter

核心格式化节点。输入自然语言或标签集，输出 NewBie XML 或 Anima 文本提示词。

输入参数：image（可选，多模态反推）、api_key、api_url、model_name、mode（NewBie/Anima）、thinking（深度思考开关）、agent_effort（Agent 等级）、user_text

输出：xml_out（NewBie: XML 提示词 / Anima: Prompt 部分）、text_out（NewBie: 额外说明 / Anima: 中文解释）

配置文件中的 api_key 和 api_url 优先于节点 UI 输入，防止 API Key 随工作流泄露。

XML Style Injector

将画师和风格信息注入到提示词中。支持 NewBie（XML）和 Anima（纯文本）两种模式。

输入：xml_input、mode、preset（预设风格）、artist_add（额外画师）、style_add（额外风格）

NewBie 模式：查找 XML 中 <artist> 和 <style> 标签并替换为预设内容。

Anima 模式：画师注入到质量词行之后（@画师名 格式），风格串追加到末尾。自动清洗括号、artist: 前缀、冒号权重等。

Style Preset Saver

从当前提示词中自动提取 <artist> 和 <style> 标签，保存为新的风格预设到配置文件。仅支持从 XML 格式（NewBie 模式）提取，保存后的预设可在两种模式下使用。

核心亮点
告别「角色串色」与「排版翻车」

平时用 AI 画图时，你是否也遇到过这些烦恼：想让两个角色一左一右坐着喝茶，AI 却总是把她们画重叠或搞混衣服特征；想做一张带标题的海报，却很难用文字说清标题、副标题和人物各自该放在哪个角落；面对长串的英文标签和复杂的坐标数字，不知从何下手。

MOSS 在线画板正是为了解决这些问题而设计的。你不需要背诵任何英文标签，也不用自己计算像素坐标——只需要在画布上像搭积木一样拉出几个方框，或者直接用中文把想法告诉右侧的 AI 助手「秋枫」，就能轻松定好画面构图、自动生成全套专业提示词。

三分钟认识画板工作台

从秋月空间首页点击 「MOSS 在线画板」（或直接访问 /moss），你会看到一个分为上、左、中、右四个区域的工作台（手机访问时可通过顶部的「画布 / 属性 / AI 对话」标签随时切换）：

  • 顶部工具栏：管理你的作品。支持新建、导入/导出草稿、导出 PNG 构图参考图、点击生成图片（连接本地 ComfyUI），或点击复制提示词把排好的构图拿去生图。觉得右侧聊天栏占地方时，可随时点收起 AI 把空间让给画布。
  • 左栏（构图画布）：你和秋枫共同摆弄画面的地方。画布用不同颜色的方框区分元素类型：
  • 蓝色框：人物（如少女、飞行员）
  • 金色框：物体（如月亮、书架、茶具）
  • 粉紫色框：文字（如海报主标题、标语）
  • 青色高亮：当前被你点选中的框，拖动四角小方块即可调整大小和位置。
  • 中栏（画布与元素属性）：调整画布宽高、挑选画风预设、填写整体画面描述，以及修改每一个方框里的具体描述、可见文字和调色板。
  • 右栏（AI 助手「秋枫」）：你的专属画板搭档。无论是从零构思画面、查标签、选画风，还是修改某个局部动作，直接跟她打字聊天即可。

左、中、右三栏之间的两条竖线都可以用鼠标左右拖动，自由调整面板宽窄，不会影响画布本身的像素尺寸。

构图实战与排版技巧

画布上的方框并不是死板的格子，它们可以重叠、嵌套、大框套小框。点击展开下方四个真实场景案例，把透明构图框叠在成图上，一眼就能掌握排框诀窍：

案例一：海报与封面排版（人物、景物与多层文字分离）

制作活动封面、宣传图或贺图时，可以把背景里的重要景物（如月亮）、前景人物和不同层级的标题分成独立的框。

排框诀窍： 把页眉小字、主标题、副标题分别建成独立的「文字」框，并在中栏填好各自要显示的文字原文。人物框和文字框稍微有一点交叠也没关系，画面反而更有前后层次感。

可以直接复制给秋枫的指令示例：

720×720，做一张方形封面。右上角是一轮弯月，右下方是戴耳机的金发少女；左上角写小字“WENQIUYUE · 问秋月 PRESENTS”，中间偏左分两行写手写体大标题“15 Billion Tokens”和“问秋月 · 壹佰伍拾亿词元”，底下再加一行小副标题。
案例二：双人互动与远近景深（大框套小框）

画多个人物和丰富场景时，用大框定背景，再用小框锁定前景角色和桌面道具，角色之间就绝不会「串衣服」或「抢位置」。

排框诀窍： 4 物体 框住整扇大窗户和窗外云海，5 物体 框住最左边的书架；1 人物 和 2 人物 一左一右对坐；中间用 3 物体 单独框出桌上的茶壶和三层甜品架。

可以直接复制给秋枫的指令示例：

1280×720，画两位少女在窗边圆桌喝下午茶：左边金发双马尾少女端着茶杯，右边白发马尾少女托腮微笑，中间桌上放着茶具和甜点，背景是大窗户外的云海远山，最左边有木头书架。
案例三：复杂动作与精致道具（把同一角色拆成多个框）

当你想画拔刀、弹琴等精细动作，只用一个大人物框往往很难控制手部和武器的位置。这时可以把同一个人的不同部位拆开框定。

排框诀窍： 用 1 人物 控制整个人物的范围，里面再用 2 人物 框住头部表情、3 人物 框住握刀的右臂、4 人物 框住和服上身；同时用 5 物体 和 6 物体 精准标出刀柄和刀鞘的走向，外围加上 7 物体 铺满飘落的樱花。

可以直接复制给秋枫的指令示例：

帮我画一位白发红瞳的和服武士少女正在拔刀，用多个框把她的头部特写、右手握刀柄的动作、刀鞘走向分开控制，背景加上飘落的樱花瓣。
案例四：大透视场景与微小细节定位

在大透视场景里，哪怕是远处航母甲板上的一团火光，或是船头一个小小的编号，都可以用小框精准锚定。

排框诀窍： 左半边用大框定住前景的战机座舱和女飞行员，右半边层层框出远处的海面航母、空中的战机群与极光、甲板上的爆炸火光，并在航母船头放一个小小的 4 文字 框。

可以直接复制给秋枫的指令示例：

1280×720，第一视角战机座舱内坐着白发女飞行员，右侧窗外下方海面是一艘正在遇袭起火的航母，空中还有战机群与极光；在航母舰艏位置留一个微小文字区域。
改画与精修的三大法宝
点选元素「局部修改」：指哪改哪，绝不误伤

想改某个人的动作或某行字，又怕 AI 把其他已经排好的部分乱改一通？

  • 操作方法：直接在左侧画布上点击你要改的那个方框（按住键盘 Shift 键可点选多个，也可以在中栏元素列表里打勾）。这时右下角聊天输入框上方会出现一行提示：当前选中：X ×。
  • 保护效果：只要带着这个选中提示发消息（例如「把这个选中角色的衣服改成白色水手服」），系统就会自动锁死其他所有未被选中的元素，只允许秋枫修改你选中的那几个框和整体氛围描述。
  • 恢复全局修改：点一下提示条上的 ×，或在画布空白处点一下取消选中，即可回到修改整张画面的状态。
勾选「锁定布局」：保住排版，只改画风和细节

如果你已经把所有方框的位置、大小和文字内容调得非常满意，只想让秋枫帮你换个画风，或者把英文描述写得更细腻：

  • 操作方法：把中栏画布设置下方的 「锁定布局」 打上勾，再去跟秋枫提要求。
  • 保护效果：开启后，画布尺寸、方框数量、每个框的位置大小以及文字框里的字都会被牢牢固定，秋枫只会帮你润色画面描述和标签。
35 种精选画风预设与实时色块调色板

不知道怎么用语言形容想要的画风和配色？

  • 挑选内置预设：点开中栏的 「风格预设」 下拉菜单，内置 35 种精心调校的画风（如「彩纸马赛克：碎片色彩」「刮刀厚涂：大胆色面」等），选中后可展开查看风格原文。
  • 让秋枫挑选或原创：你也可以在聊天时对秋枫说「帮我从风格库里挑一个适合这张图的画风」，或者说「不用预设风格，帮我自己设计一种复古胶片水彩风」。
  • 调色板色块预览：点开中栏的「全局更多属性」或「元素更多属性」，在调色板里输入颜色英文名或十六进制色号（如 #ff99aa, skyblue），输入框下方会立刻显示出直观的彩色小色块。

对齐排版、透明叠图导出与本地备份
  • 一键对齐与等距排列：画布左下角设有一排排版按钮。按住 Shift 选中 2 个以上方框，即可使用 「左对齐」「水平居中」「右对齐」；选中 3 个以上方框，即可使用 「水平均布」「竖直均布」，排列多行文字或分镜格时瞬间整整齐齐。
  • 随时撤销与重做：无论是自己拖歪了框，还是觉得秋枫刚改的一版不如上一版，直接点击画布左上角的 「撤销」（快捷键 Ctrl + Z），或点击秋枫聊天回复下方的 「撤销本次修改」，即可一键退回原样。
  • 导出 PNG 透明框线图：点击顶部 「导出 PNG」，除了「原样导出」外，还可选择 「导出透明框线与标签」（支持调节框线粗细、字号与深色外描边）。它会生成一张背景全透明、只带彩色框线与编号标签的图，方便你叠在任何成图上核对位置。
  • 自动保存与草稿导入导出：草稿、生成底图和对话记录都会自动保存在当前浏览器中，刷新页面不会丢失。清理浏览器缓存或跨设备使用前，可点击顶部 「导出草稿」 保存为 .json 文件，下次点击 「导入草稿」 即可继续编辑。

点发送没反应，中栏下方出现红字提示 1. 处于局部修改状态（只选中了部分方框），但画布上还有未选中的空方框没填描述；<br>2. 勾选了「锁定布局」，但画布上有「文字」框还没填实际可见文字。 按中栏红字提示补齐空缺的描述或文字；或者先点画布空白处取消选中、取消勾选「锁定布局」再发送。
点击「复制提示词」提示无法导出 画布还没设宽高、全局描述为空、没有任何方框，或某个方框漏填了描述/可见文字。 看一眼中栏底部的提示文字，缺哪项补哪项（或直接让秋枫帮你补全），再点击复制即可。
修改画布尺寸后，原来的生成底图不见了 生成的底图与当时的画布构图尺寸绑定，改变尺寸比例后为防止画面变形会自动隐藏。 把画布尺寸改回生成该图时的宽高，底图就会重新显示；或者在新尺寸下重新点一次「生成图片」。
连接本地 ComfyUI 提示连接失败 ComfyUI 未启动、未追加跨域启动参数重启，或浏览器拦截了本地网络访问权限。 确认本机 ComfyUI 正在运行，复制「ComfyUI 设置」里的启动参数加到启动命令末尾并重启 ComfyUI，同时在浏览器地址栏权限设置中允许「本地网络访问」。
秋枫提示任务暂停，让输入「继续」 画面要求非常细致，秋枫单轮搜索标签和调整画板的步骤达到了单次上限（17 步）。 前面的进度都已完整保留，直接在聊天框发送「继续」两个字，她就会接着把剩下的步骤做完。

Anima-yoshinari-ko
模型介绍

下载链接：https://huggingface.co/SAkizuki/Anima-yoshinari-ko

本模型是一个基于 Anima 训练的 LoKR（Low-Rank Kronecker Product） 画风适配器，目标是捕捉《向山进发4》（Yama no Susume: Next Summit）BD 版 Non-Credit ED 动画截图中呈现的吉成鋼画风特征——手绘质感、水彩渲染、淡雅配色与柔和线条。

本模型使用 Anima Base v1.0 作为底模，训练集约 300 张来自《向山进发4》BD NCED 的动画截图，经 14 轮迭代训练而成。

请使用@yoshinari ko触发此画风，强度建议设置为0.5~1.5，过强的模型强度会对构图产生破坏。
